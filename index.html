1. 기본 원칙과 현재 제공 범위

ideaBank는 메모·분류·생각 연결 및 잠금 일기장을 제공합니다. 로그인하지 않은 기록은 기기 안에 저장합니다. 로그인·동기화 서비스는 서버와 로그인 공급자 설정이 완료된 배포본에서만 이용할 수 있습니다. 앱의 계정 화면에서 서비스 이용 가능 여부를 안내합니다.

2. 처리하는 정보와 목적

  • 로컬 메모: 내용, 분류와 분류 이력, 작성·수정 시각, 연결 및 삭제 기록을 저장합니다.
  • Apple·카카오 로그인 사용 시: 해당 공급자가 허용한 계정 식별자와 이메일, 로그인 공급자, 인증 세션을 계정 식별 및 동기화에 사용합니다. 비밀번호는 앱이 직접 수집하지 않습니다. 인증 토큰은 기기 Keychain에 보관합니다.
  • 기기 간 동기화 사용 시: 일반 메모, 분류 이력, 작성·수정 시각, 연결·삭제 정보를 Supabase에 전송합니다. 로그인 전 로컬 메모는 사용자가 가져오기를 선택한 경우에만 계정으로 복사합니다.
  • 비밀 일기: 별도 암호화 파일에 기기 내 보관합니다. PIN은 salt와 검증값으로 Keychain에 저장하며 평문으로 저장하지 않습니다. Face ID의 얼굴 정보는 운영체제가 처리하고 앱이나 서버가 받지 않습니다.
  • 분류별 위젯: 일반 메모와 분류의 사본을 앱과 위젯이 공유하는 기기 내 저장소에 저장합니다. 위젯은 선택한 분류의 메모 내용을 표시하므로 홈 화면·바탕화면에서 보일 수 있습니다. 비밀 일기는 위젯과 서버 동기화에서 제외합니다.

3. 외부 서비스

동기화 서비스가 활성화된 경우 Supabase를 인증·데이터 보관 처리업체로 사용합니다. 로그인은 Apple 또는 카카오가 처리합니다. 네트워크 통신 과정에서 해당 사업자가 IP 주소, 요청 시각 등 보안·운영 로그를 처리할 수 있습니다. 서버 지역 등 운영 설정은 서비스 연결 완료 시 개발 문서와 정책에 갱신합니다. 광고 SDK, 사용자 추적 SDK, 제3자 AI 분석 서비스는 현재 앱에 포함하지 않습니다.

4. 보관과 삭제

사용자가 기록을 삭제하거나 계정을 삭제할 때까지 필요한 정보를 보관합니다. 동기화에서 삭제한 메모가 되살아나는 것을 막기 위해 삭제된 메모의 식별자와 삭제 시각을 계정 삭제 시까지 보관할 수 있습니다. 직접 만든 분류 이력은 해당 분류의 마지막 메모를 지워도 유지됩니다.

계정 삭제 기능이 연결된 배포본에서는 계정 화면에서 본인의 서버 계정과 동기화 기록을 삭제할 수 있습니다. 다른 기기에 남은 오프라인 사본, 로그인 전 로컬 메모, 비밀 일기는 해당 기기에서 별도로 삭제해야 합니다. 로그아웃은 계정 삭제가 아닙니다. 앱 삭제는 서버 계정 삭제가 아니며, 운영체제 Keychain에 보관된 보안 정보가 남을 수 있습니다. 기기·서버의 백업 사본은 해당 서비스의 보관 정책에 따라 처리됩니다.

5. 보호 조치와 이용자 선택

서버 통신에는 HTTPS를 사용하고, 동기화 데이터는 계정 소유자만 접근하도록 데이터베이스 접근 정책을 적용합니다. 비밀 일기는 AES-GCM 암호화와 PIN 또는 지원 기기의 Face ID 잠금을 적용합니다. Mac 등 Face ID 미지원 기기에서는 PIN을 사용합니다. 로그인하지 않고 로컬 기록을 사용할 수 있으며, 위젯은 사용자가 직접 추가·제거합니다.
